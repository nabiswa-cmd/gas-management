# Gas Cylinder Management System (Flask + PostgreSQL)

This project helps manage gas stock, sales, and returns across multiple stations.  
Built using **Flask**, **PostgreSQL**, and **Python**, it allows user login, dashboards, and live updates.

## Features
- User authentication
- Gas stock tracking
- Sales and refill management
- Prepaid customer handling
- Source-specific reports (Kipsongo, Mama Pam, External)

## Tools Used
- Python, Flask, PostgreSQL, HTML/CSS, GitHub
